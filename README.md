# 대시보드 OS — 역 계획서 · 쇼케이스

**목적은 진척률이 아니라 지식이다.** `my-setup-proj`(개인 생산성 대시보드 OS)는 흩어진
프로젝트·경험을 시각화·도식화해 지식의 가치를 올리고, 그 지식이 쌓여 역량이 느는 방향을
한눈에 보이게 한다. 코드는 [gamercross/my-setup-proj](https://github.com/gamercross/my-setup-proj)
에 있고, 이 저장소는 그 프로젝트의 **회고 문서와 발표용 페이지**만 따로 모아 GitHub Pages 로 공개한다.
